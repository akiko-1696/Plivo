Experiments Performed

Run 1 (Selected)

The optimizer was changed from Adam to AdamW. Cosine learning rate scheduling and gradient clipping were added to improve optimization stability while preserving the provided architecture. This configuration achieved the best measured development BPB and was selected as the final submission.

Run 2

Weight tying and GPT-2 style initialization (standard deviation reduced from 0.05 to 0.02) were evaluated. Under the fixed training budget of 2000 optimization steps, these modifications did not produce a measurable improvement in development BPB compared to Run 1.

Final Configuration

  • Optimizer: AdamW
  • Learning Rate: 3e-4
  • Weight Decay: 0.1
  • Betas: (0.9, 0.95)
  • CosineAnnealingLR scheduler
  • Gradient clipping (max norm = 1.0)
  • 2000 training steps
  • Development BPB: 2.3718

Why This Configuration Was Selected

Among the completed experiments, the optimizer improvements produced the lowest measured development BPB while maintaining stable optimization throughout training. Although weight tying and GPT-2 style initialization were also explored, they did not improve the evaluation metric within the fixed training budget. Therefore, the optimizer-only configuration was selected for the final checkpoint.

Human vs Machine Contribution

The human contributor analyzed the starter implementation, selected the experiments to perform, modified the source code, executed all training and evaluation locally, interpreted the experimental results, chose the final checkpoint based on the measured BPB, and prepared the final submission.
